## 1. Download the extension

Click [here](https://omocaptcha.com/vi/extension) to open the folder that contains the extensions

Once you have successfully accessed the site, select the browser for which you wish to install the extension. For example, if you want to install the extension for Chrome, choose to download the ZIP file for Chrome.

![Image](/images/image-5.png "Image")

## 2. Extract the extension

After downloading in step 1 you will have the zip file:

<Frame>
  ![Downloaded zip file](/images/huong-dan/cai-extension/03-file-zip-tai-ve.png)
</Frame>

Extract the zip. If a password prompt appears, enter `12345`.

<Frame>
  ![Enter password 12345](/images/huong-dan/cai-extension/04-nhap-mat-khau.png)
</Frame>

Once extracted successfully you will get a folder like this:

<Frame>
  ![Extracted extension folder](/images/huong-dan/cai-extension/05-thu-muc-giai-nen.png)
</Frame>

## 3. Install the extension into Chrome

Open Chrome and go to `chrome://extensions/`. The page looks like this:

<Frame>
  ![chrome://extensions page](/images/huong-dan/cai-extension/06-trang-extensions.png)
</Frame>

In the top-right corner, look for the **"Developer mode"** switch. If it is off, turn it on:

<Frame>
  ![Enable Developer mode](/images/huong-dan/cai-extension/07-bat-developer-mode.png)
</Frame>

Then click the **"Load unpacked"** button:

<Frame>
  ![Click Load unpacked](/images/huong-dan/cai-extension/08-tai-tien-ich-da-giai-nen.png)
</Frame>

A folder-picker dialog appears. Navigate to the extracted extension folder from step 2, then click **"Select Folder"**:

<Frame>
  ![Select the extension folder](/images/huong-dan/cai-extension/09-chon-thu-muc.png)
</Frame>

After selecting, Chrome will show the extension like below — the installation was successful:

<Frame>
  ![Extension installed successfully](/images/huong-dan/cai-extension/10-cai-thanh-cong.png)
</Frame>

<Tip>
  Once installed, [set your API key for the extension](/en/guides/set-api-key-for-extension) to start using it.
</Tip>

<Warning>
  If the extension does not work, toggle it off/on or restart your browser.
</Warning>
