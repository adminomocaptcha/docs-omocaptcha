Picking 2 objects on the web is a common captcha type on TikTok.

<Frame caption="Example of the 'Pick 2 objects with the same shape' TikTok captcha">
  ![Tiktok select object modal](/images/tiktok-select-object-modal.png)
</Frame>

## 1. Create the task

### Request

```http
POST https://api.omocaptcha.com/v2/createTask
```

| Parameter | Type | Required | Description |
| --- | --- | :-: | --- |
| `clientKey` | String | ✅ | Your client API key |
| `task.type` | String | ✅ | Captcha service class name — `TiktokSelectObjectWebTask` |
| `task.imageBase64` | String | ✅ | Base64-encoded challenge image <br /> <img src="/images/tiktok-select-object-image.png" alt="Challenge image" style={{ width: "100%", maxWidth: "260px", marginTop: "8px" }} /> |
| `task.widthView` | Number | ✅ | Rendered image width on the web (px) <br /> <img src="/images/tiktok-width-view.png" alt="widthView" style={{ width: "100%", maxWidth: "260px", marginTop: "8px" }} /> |
| `task.heightView` | Number | ✅ | Rendered image height on the web (px) <br /> <img src="/images/tiktok-height-view.png" alt="heightView" style={{ width: "100%", maxWidth: "260px", marginTop: "8px" }} /> |
| `task.question` | String | ✅ | Captcha question (e.g. `Which of these objects are used in hoops?`) |

<Info>
  `widthView` and `heightView` are the image dimensions **as rendered on the page** (not the original image size). Right-click the image → _Inspect element_ to read the correct values.
</Info>

### Response

**Success:**

```json
{
  "errorId": 0,
  "taskId": "49f9f60a-c809-4af0-93c0-0409b72e67e0"
}
```

The server returns `errorId = 0` with a `taskId` when the task is created successfully.

**Failure:**

```json
{
  "errorId": 1,
  "errorCode": "",
  "errorDescription": ""
}
```

The server returns `errorId = 1` and the corresponding `errorCode`.

## 2. Get the result

### Request

```http
POST https://api.omocaptcha.com/v2/getTaskResult
```

```json
{
  "clientKey": "OMO_API_KEY",
  "taskId": "49f9f60a-c809-4af0-93c0-0409b72e67e0"
}
```

### Response

**Success:**

```json
{
  "errorId": 0,
  "status": "ready",
  "solution": {
    "pointA": { "x": 50, "y": 30 },
    "pointB": { "x": 100, "y": 70 }
  }
}
```

The server returns `errorId = 0` and `status = ready`. Read the two click points from `solution.pointA` and `solution.pointB`.

<Tip>
  `x` and `y` are given in the rendered image coordinate system (based on `widthView` × `heightView`). Click those two points and then press **Confirm**.
</Tip>

**Processing:**

```json
{
  "status": "processing",
  "errorId": 0,
  "errorCode": "",
  "errorDescription": ""
}
```

The server returns `errorId = 0` and `status = processing`. Wait 2 seconds and poll again.

**Failure:**

```json
{
  "errorId": 1,
  "errorCode": "ERROR_JOB_STATUS",
  "errorDescription": "Job failed",
  "status": "fail",
  "solution": {}
}
```

The server returns `errorId = 1` — see [Error Codes](/en/api/error-codes) for handling.
