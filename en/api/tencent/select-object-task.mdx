Select-object captcha is a common image challenge where the user must pick the tiles that match the given question (or anchor image) from a grid.

## 1. Create task

**Endpoint:** `POST https://api.omocaptcha.com/v2/createTask`

### Parameters

| Parameter | Type | Required | Description |
| --- | --- | :-: | --- |
| `clientKey` | `String` | ✅ | Your account API key. |
| `task.type` | `String` | ✅ | `TencentSelectObjectTask` |
| `task.imageBase64` | `String` | ✅ | Base64-encoded captcha image.<br /><img src="/images/tencent-select-object-image.png" style={{ maxWidth: "260px", width: "100%" }} /> |
| `task.question` | `String` | ✅ | Captcha question (e.g. `choose the most alike`). |
| `task.anchor` | `String` | ❌ | Base64-encoded anchor image (if present), usually shown next to the question.<br /><img src="/images/tencent-select-object-anchor.png" style={{ maxWidth: "120px", width: "100%" }} /> |

### Request example

<CodeGroup>

```bash cURL
curl -X POST https://api.omocaptcha.com/v2/createTask \
  -H "Content-Type: application/json" \
  -d '{
    "clientKey": "YOUR_API_KEY",
    "task": {
      "type": "TencentSelectObjectTask",
      "imageBase64": "BASE64_IMAGE",
      "question": "choose the most alike",
      "anchor": "BASE64_ANCHOR"
    }
  }'
```

```javascript Node.js

```

## 2. Get task result

**Endpoint:** `POST https://api.omocaptcha.com/v2/getTaskResult`

```json
{
  "clientKey": "YOUR_API_KEY",
  "taskId": "49f9f60a-c809-4af0-93c0-0409b72e67e0"
}
```

### Response example

```json
{
  "errorId": 0,
  "status": "ready",
  "solution": {
    "objects": [4, 5]
  }
}
```

`solution.objects` is a list of zero-based tile indices to click, counted left-to-right, top-to-bottom.
