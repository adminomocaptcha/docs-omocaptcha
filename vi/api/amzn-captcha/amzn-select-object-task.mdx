Chọn đối tượng là một loại hình ảnh xác thực phổ biến của Amazon. Người dùng cần chọn tất cả các ô ảnh khớp với chủ đề trong câu hỏi từ một lưới 3x3.

## 1. Tạo yêu cầu

**Request**

```text
POST https://api.omocaptcha.com/v2/createTask
```

| Tham số | Kiểu | Bắt buộc | Mô tả |
| --- | --- | :-: | --- |
| `clientKey` | `String` | ✅ | Khóa tài khoản khách hàng |
| `task.type` | `String` | ✅ | Tên class dịch vụ captcha cần giải |
| `task.imageBase64` | `String` | ✅ | Hình ảnh lưới 3x3 được mã hóa base64<br /><br /><img src="/images/amzn-select-object-grid.png" style={{ maxWidth: "260px", width: "100%" }} /> |
| `task.other` | `String` | ✅ | Văn bản câu hỏi captcha <br /><img src="/images/amzn-select-object-question.png" style={{ maxWidth: "260px", width: "100%" }} /> |

</CodeGroup>

**Response**

Thành công:

```json
{
  "errorId": 0,
  "taskId": "49f9f60a-c809-4af0-93c0-0409b72e67e0"
}
```

Máy chủ sẽ trả về `errorId = 0` và `taskId` khi tạo yêu cầu thành công.

Thất bại:

```json
{
  "errorId": 1,
  "errorCode": "",
  "errorDescription": ""
}
```

Máy chủ sẽ trả về `errorId = 1` cùng với `errorCode` mã lỗi tương ứng.

## 2. Nhận kết quả yêu cầu

**Request**

```text
POST https://api.omocaptcha.com/v2/getTaskResult
```

```json
{
  "clientKey": "OMO_API_KEY",
  "taskId": "49f9f60a-c809-4af0-93c0-0409b72e67e0"
}
```

**Response**

Thành công:

```json
{
  "errorId": 0,
  "status": "ready",
  "solution": {
    "objects": [0, 1, 2, 3]
  }
}
```

Máy chủ sẽ trả về `errorId = 0` và `status = ready`. Đọc kết quả trong `solution`.

<Tip>
  Mảng `objects` chứa chỉ số các ô ảnh cần chọn trong lưới 3x3, đánh số từ **0 đến 8**, theo thứ tự từ **trái sang phải, trên xuống dưới**:

  ```text
  0 | 1 | 2
  3 | 4 | 5
  6 | 7 | 8
  ```

  Sau khi click các ô tương ứng, nhấn nút **Confirm** để hoàn tất xác thực.
</Tip>

Đang xử lý:

```json
{
  "status": "processing",
  "errorId": 0,
  "errorCode": "",
  "errorDescription": ""
}
```

Máy chủ sẽ trả về `errorId = 0` và `status = processing`, yêu cầu đang được xử lý. Vui lòng chờ 2 giây rồi yêu cầu lại.

Thất bại:

```json
{
  "errorId": 1,
  "errorCode": "ERROR_JOB_STATUS",
  "errorDescription": "Job failed",
  "status": "fail",
  "solution": {}
}
```

Máy chủ sẽ trả về `errorId = 1` khi yêu cầu thất bại.
