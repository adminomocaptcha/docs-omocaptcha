## 1. Tải extension

Bấm vào [đây](https://drive.google.com/drive/folders/1) để đến thư mục chứa các extension.

Sau khi truy cập thành công, hãy chọn trình duyệt bạn muốn cài. Ví dụ nếu muốn cài extension cho Chrome, hãy truy cập thư mục **Chrome**.

<Frame>
  ![Chọn trình duyệt](/images/huong-dan/cai-extension/01-chon-trinh-duyet.png)
</Frame>

Trong thư mục sẽ chứa các file nén như sau. Ở đây có một file zip, file này là extension **phiên bản mới nhất**. Chúng tôi khuyên bạn nên tải bản mới nhất.

<Frame>
  ![File zip extension trên Drive](/images/huong-dan/cai-extension/02-file-zip-drive.png)
</Frame>

## 2. Giải nén extension

Sau khi tải thành công ở bước 1, chúng ta sẽ có file zip như sau:

<Frame>
  ![File zip đã tải về](/images/huong-dan/cai-extension/03-file-zip-tai-ve.png)
</Frame>

Tiếp tục giải nén file zip này. Nếu trong quá trình giải nén hiện thông báo nhập mật khẩu, hãy nhập mật khẩu là `12345`.

<Frame>
  ![Nhập mật khẩu 12345](/images/huong-dan/cai-extension/04-nhap-mat-khau.png)
</Frame>

Sau khi giải nén thành công, chúng ta sẽ được thư mục như sau:

<Frame>
  ![Thư mục extension đã giải nén](/images/huong-dan/cai-extension/05-thu-muc-giai-nen.png)
</Frame>

## 3. Cài extension vào Chrome

Mở Chrome lên rồi truy cập vào URL `chrome://extensions/`. Sau khi truy cập thành công, giao diện sẽ như sau:

<Frame>
  ![Trang chrome://extensions](/images/huong-dan/cai-extension/06-trang-extensions.png)
</Frame>

Hãy để ý ở góc bên phải có nút **"Chế độ dành cho nhà phát triển"**. Nếu đang tắt thì hãy bật lên:

<Frame>
  ![Bật chế độ dành cho nhà phát triển](/images/huong-dan/cai-extension/07-bat-developer-mode.png)
</Frame>

Tiếp tục bấm vào nút **"Tải tiện ích đã giải nén"**:

<Frame>
  ![Bấm Tải tiện ích đã giải nén](/images/huong-dan/cai-extension/08-tai-tien-ich-da-giai-nen.png)
</Frame>

Sẽ hiện lên tab chọn thư mục. Bây giờ hãy tìm đến thư mục extension đã giải nén ở bước 2, rồi bấm vào nút **"Select Folder"** để chọn thư mục:

<Frame>
  ![Chọn thư mục extension](/images/huong-dan/cai-extension/09-chon-thu-muc.png)
</Frame>

Sau khi chọn xong, trong trình duyệt sẽ hiện như sau — nghĩa là chúng ta đã cài extension thành công:

<Frame>
  ![Cài extension thành công](/images/huong-dan/cai-extension/10-cai-thanh-cong.png)
</Frame>

<Tip>
  Sau khi cài xong, bạn hãy [thiết lập API key cho extension](/vi/huong-dan/set-api-key-cho-extension) để bắt đầu sử dụng.
</Tip>

<Warning>
  Nếu extension không hoạt động, hãy tắt/bật lại công tắc của extension hoặc khởi động lại trình duyệt.
</Warning>
